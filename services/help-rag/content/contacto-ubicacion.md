# Cambiar contacto, dirección y coordenadas

## Cambiar número de contacto

Abre tu perfil, entra a la tienda y edita el teléfono de contacto. Guarda el cambio y revisa la vista pública para confirmar que el número correcto aparece para clientes. Si el teléfono se usa para verificación, podrías recibir un código.

## Cambiar dirección

Edita calle, colonia, municipio y referencias. Usa una dirección que ayude a llegar al local o que describa correctamente la zona de atención. Los cambios de dirección pueden requerir revisión para evitar ubicaciones falsas.

## Cambiar coordenadas

Si el mapa permite ajustar el pin, mueve la ubicación al punto correcto y guarda. Si no puedes mover el pin o las coordenadas quedan mal, escribe a hola@andar.mx con el nombre del negocio, dirección correcta y una referencia del lugar.

## Recomendaciones de ubicación

Mantén coherencia entre dirección escrita, coordenadas y zona de atención. Una ubicación precisa mejora la experiencia en el mapa de exploración y evita visitas perdidas.
