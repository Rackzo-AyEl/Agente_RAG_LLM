# Registro de cuenta en Andar.mx

## Para qué sirve la cuenta

La cuenta permite entrar a Andar.mx, guardar tu perfil, administrar tiendas y usar servicios para mostrar tu negocio a clientes cercanos. La cuenta puede pertenecer a una persona comerciante, colaboradora o usuaria que explora negocios.

## Cómo me registro

Entra a la página de inicio de Andar.mx y selecciona la opción de registro. Captura tu nombre, correo electrónico o teléfono, crea una contraseña segura y acepta los términos y condiciones. Si el sistema envía un código de verificación, escríbelo antes de continuar.

## Problemas con el código

Si el código no llega, revisa que el correo o teléfono estén bien escritos. También verifica spam, señal móvil y que no exista un bloqueo de mensajes. Si el problema continúa, escribe a hola@andar.mx con el dato que intentaste registrar.

## Después del registro

Cuando la cuenta queda activa, puedes completar tu perfil, crear una tienda, explorar el mapa o revisar servicios premium. Si quieres publicar un negocio, el siguiente paso recomendado es crear la tienda desde el asistente de nueva tienda.
